## Emails

- Templates in `supabase/functions/_shared/email/`, one file per email. `notify` and `request` load data, pick a template and send; they hold no markup.
- `npm run email:preview` renders all of them with sample data and checks them. Run it after any change to the folder.
- Images load from `cartandkeep.com/email/logo.png` and `mark.png`, so the site must be deployed before a template that needs a new image.

## Deploying edge functions

- `notify` and `request` deploy with the CLI only. The dashboard editor cannot see `_shared` and would break both.
  ```
  npx supabase functions deploy notify --project-ref vtdqrhkjdzkdjmyxrsok
  npx supabase functions deploy request --project-ref vtdqrhkjdzkdjmyxrsok
  ```
- `supabase/config.toml` sets Verify JWT for all 17 functions to match live. A CLI deploy applies it, and a function with no entry deploys with JWT on. Only `stripe-webhook` is off; turning it on stops orders being marked paid.
- Any other function can still go through the dashboard, but if it is ever deployed by CLI, check its entry first.
- The CLI must be logged in as the account that owns the project. `npx supabase projects list` should show `vtdqrhkjdzkdjmyxrsok`.
