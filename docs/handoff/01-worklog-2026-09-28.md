### Basket and Saved

- The heart in the basket only saves. Remove leaves an Undo row. Saved used to take things out of the basket; that was the bug reported.
- Saved rebuilt as rows with price since saved, stock, in-basket state, a panel that adds everything to the basket, and a share link (`/list?i=..&n=Name`, product ids packed, first name only).
- Saved hero with pinned photos and fact pills, after "very lazy, no creativity, no icons" on the first version.
- Empty basket state, and the 404 rebuilt with search and live sections (it listed old eBay departments).
- Home shelves were squashed on the live site: width now from the cell count, not `fit-content`.

### After paying

- Order page: stage kicker, copyable reference ticket, three stops (Paid, Leaves us, With you) with dates worked out the same way as checkout, the parcel label with a round PAID postmark, a Sent panel with carrier tracking, a review prompt once it is due, and the conversation card.
- Receipt: prints to one clean A4 page with no page address or token in the browser footer, and saves as `REFERENCE YYYY-MM-DD HH-MM` (no brand in front, as asked). Packing slip named the same way.
- Track an order: lists orders opened on this device (localStorage `ck.orders.v1`, no address or email stored), each with a mini journey and the one date that matters. Finding a different order sits behind "Looking for a different order?" rather than on the page.

### Emails

Every email the shop sends was redrawn, then moved out of `notify` into its own folder.

- `supabase/functions/_shared/email/`: `kit.ts` (the parts), `dates.ts` (working days and bank holidays), `context.ts` (shop name, site, legal line), `rights.ts` (the statutory section), `send.ts` (Resend), and one file per email in `templates/`.
- Eleven emails: confirmation, dispatch, gift recipient, review request, question received, reply (with an optional price), sale, customer message to the shop, nearly out, someone wants, and the studio's eBay pull alert.
- The order reference is a ticket, set large, and in the subject line. Before, it was an afterthought.
- Confirmation carries a Track your order button and the receipt link. The site already told people the link was in the email; now it is.
- Review email has five stars; each opens the review page with that rating chosen (`?rating=`).
- Every email goes with a plain text part.
- `npm run email:preview` renders every email from the real templates with sample data into `scripts/email/out/`, and fails on a dash, a broken value, or a size near Gmail's 102KB clip.
- Logo and mark hosted at `cartandkeep.com/email/`, flattened on cream.
- Missing 30 August 2027 bank holiday added. The email list and `src/utils/delivery.js` now agree.
- Addresses carry an invisible joiner after each digit so Gmail does not turn them into blue map links.

### Deploying functions moved to the CLI

- `notify` and `request` import the shared folder, which the dashboard editor cannot bundle. They deploy with `npx supabase functions deploy <name> --project-ref vtdqrhkjdzkdjmyxrsok` only.
- `supabase/config.toml` holds Verify JWT for all 17 functions, matching the live project as read on 28 September. Only `stripe-webhook` is off.
- First CLI login landed on the wrong Supabase account (403). Logging out and in with the browser on the right account fixed it.
