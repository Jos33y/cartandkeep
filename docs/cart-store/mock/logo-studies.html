Before it ships

The ampersand here is live text in Archivo, so it depends on the font loading. In production it becomes a path, which removes the dependency and makes the file a third of the size. One command: npx svgo --config=svgo.config.js after outlining in any vector editor, or inkscape --export-text-to-path.
